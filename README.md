# secure-connection-for-the-messenger
Небольшой системный модуль написанный для курсовой работы.

Необходим для выстраивания системы безопасности в рамках учебного проекта по разработке мессенджера.

Модуль включает в себя пользовательский и серверный клиенты, протоколы шифрования написанные с использованием TLS-протоколов и зачаточную системы лицензирования по принципу сертифицирования

Работа модуля, используемые инструменты при его разработке и инструкция по использованию, описаны в файле KursovayaV2.pdf
